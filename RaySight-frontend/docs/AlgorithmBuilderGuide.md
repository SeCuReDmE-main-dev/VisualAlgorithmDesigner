# Algorithm Builder User Guide

## Overview

The Algorithm Builder is the linear step tool inside Visual Algorithm Designer. It helps students write an algorithm as ordered instructions, reorder steps, and watch the sequence run one step at a time.

## Accessing The Algorithm Builder

1. Open the VAD application in your browser.
2. Select **Algorithm Builder** from the main navigation.

## Interface

* **New Step Description:** type one step of your algorithm.
* **Add Step:** add the typed step to the list.
* **Algorithm Steps:** reorder steps with drag-and-drop or delete a step.
* **Generate Algorithm with AI:** paste multiple lines and convert them into steps. This is a text helper for classroom drafting, not a hidden provider route.
* **Run Algorithm:** play the sequence and highlight each active step.

## Adding Steps

1. Type a step such as `Read the player's score`.
2. Click **Add Step**.
3. Repeat until the algorithm is complete.

## Reordering Steps

1. Click and hold a step card.
2. Drag it to the new position.
3. Release it and confirm the numbering updates.

## Generating From Multiple Lines

Paste one step per line:

```text
Start
Read input A
Read input B
If A > B, print A
Otherwise, print B
End
```

Click **Generate with AI**. Existing steps are replaced by the generated list and empty lines are ignored.

## Running The Algorithm

Click **Run Algorithm** to highlight each step in order. Use this to check whether the algorithm is clear before moving to the visual VAD canvas.
